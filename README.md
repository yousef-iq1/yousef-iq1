# Yousef Ali

I’m a full-stack web developer. I work with React and TypeScript on the frontend, and Node.js, Express and PostgreSQL on the backend. My projects cover interactive interfaces, authentication, APIs and Arabic/English layouts.

[Portfolio](https://yousef-portfolio-63jd.onrender.com)

## Selected projects

**[Multilingual CMS](https://github.com/yousef-iq1/multilingual-cms)**  
A publishing app with an authenticated editor, drafts, translations and media uploads. React and TypeScript connect to an Express API, with PostgreSQL and Supabase behind the content workflow.

**[Seen It](https://github.com/yousef-iq1/Seen-it)** · [Demo](https://seen-it-zae7.onrender.com)  
Movie and TV discovery with swipe-based recommendations, accounts and shareable lists. Built with React 19, Next.js, Zustand and Supabase, with responsive Arabic and English interfaces.

**[IQD Market Tracker](https://github.com/yousef-iq1/iqd-market-tracker)** · [Demo](https://iqd-market-tracker-g192.onrender.com)  
An IQD/USD dashboard with exchange-rate history, interactive Recharts charts and a converter. The React frontend gets its data through an Express API.

**[Arabic Search Context Lab](https://github.com/yousef-iq1/arabic-search-context-lab)** · [Demo](https://arabic-search-context-lab-prod.onrender.com)  
A Next.js and SerpApi project comparing the same Arabic query across four cities. The public demo uses saved results; the code also includes server-side live requests and result polling.
